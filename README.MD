## SENSEI

This is a dervied version of Sensei developed specifically for the GMTK game jam which includes the ***Countdown*** theme. Unlike previous Sensei game (Developed BY ME) where the player had a fun parkour game , On this game  this provides a Timer Based gameplay where player has to complete the map while killing the props and getting pickups to increase their survival time which is shown beside the player sprite.

## Tools Used
- Godot
- Gd Script
- Open source assets ( from Itch.io )

## How to play 
- A and D for the movement
- Space to jump
- Shift to dash
- Eat the cherry to get 3 sec extra & Kill the mobs to get 6 seconds extra survival time
